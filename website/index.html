Answers, without the spin

What you should know.

Does Drip Type work in every app?+

Drip Type works system-wide in editable fields across Mac and Windows apps. Password and other operating-system-protected secure fields stay protected.

Does my writing leave my device?+

Core and Pro writing features stay on your device. Drip Type 1.7 does not use a third-party AI writing API.

Why does macOS need Accessibility permission?+

macOS requires Accessibility and Automation permission before an application can enter keystrokes into another application. Windows uses its native input engine and does not require those macOS permissions.

Can I cancel whenever I want?+

Yes. Core and Pro subscriptions can be managed or canceled through Stripe's Customer Portal.

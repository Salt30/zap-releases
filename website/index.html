Answers, without the spin

What you should know.

Does Drip Type work in every Mac app?+

Drip Type is designed for standard text fields across macOS applications and browsers. Secure or specialized fields may intentionally block automated input.

Does my writing leave my Mac?+

Core and Pro writing features stay on the Mac. Drip Type 1.6 does not use a third-party AI writing API.

Why does Drip Type need Accessibility permission?+

macOS requires Accessibility and Automation permission before an application can enter keystrokes into another application. Drip Type explains and checks both permissions during onboarding.

Can I cancel whenever I want?+

Yes. Core and Pro subscriptions can be managed or canceled through Stripe's Customer Portal.
